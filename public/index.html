    사용법

    세 단계면 끝나요

    1. 두 기기에서 이 주소 열기보내는 기기와 받는 기기 모두 브라우저로 엽니다. 받는 사람도 설치할 것이 없어요.
    2. 코드로 연결한쪽에서 새로 연결하기를 누르면 QR과 6자리 코드가 나와요. 다른 쪽에서 찍거나 입력하세요.
    3. 보내기파일이나 폴더를 끌어다 놓거나 +를 누르세요. 글도 대화처럼 주고받아요.

    장점

    왜 옮겨인가요

    설치·가입이 필요 없어요받는 사람도요. 프로그램 설치가 막힌 회사·학교 PC에서도 되고, 개인정보도 받지 않아요.
    용량 제한 없이 원본 그대로큰 영상도 나누지 않고 보내요. 사진 화질, 파일 이름, 폴더 구조가 그대로예요.
    서버에 남지 않고, 서버도 못 봐요파일을 서버에 저장하지 않아요. 종단간 암호화라 서버를 거쳐 가도 내용을 볼 수 없어요.
    올렸다 받지 않아서 빨라요가능하면 기기끼리 바로 보내요. 같은 와이파이면 인터넷을 거치지도 않아요.직접 연결이 막힌 회사망 등에서는 서버를 거쳐 가서 느릴 수 있어요.
    기기를 가리지 않아요아이폰에서 윈도우 PC로, 갤럭시에서 맥으로. 같은 주소 하나로 이어져요.
    끊겨도 이어서 보내요전송 중 끊기면 받은 지점부터 다시 보내요. 처음부터 다시 보낼 필요가 없어요.

    PC끼리 쓰면 더 좋아요 · 크롬·엣지

    폴더째, 바뀐 것만

    폴더 동기화폴더를 지정해 두면 추가·수정·삭제된 파일만 골라 상대 PC 폴더로 보내요. 어떤 줄이 바뀌었는지도 보여 줘요.
    받는 폴더 지정받은 파일이 원하는 폴더에 바로 저장돼요. 큰 파일도 브라우저 메모리를 채우지 않아요.
    연결마다 대화 기록주고받은 파일과 글이 대화처럼 쌓이고, 다음에 같은 기기와 연결하면 그대로 있어요. 기록은 이 브라우저에만 저장돼요.
    모임 앨범여럿이 찍은 사진을 한곳에 모아 원본으로 나눠 가져요.

        옮겨 사용 설명서

        시작하기

        옮겨는 폰, PC, 태블릿 사이에서 파일과 글을 원본 그대로 주고받는 서비스예요. 설치나 로그인이 필요 없고, 아이폰·갤럭시·윈도우·맥 어디서든 돼요.

        기기 연결하기

        1. 한 기기에서 새로 연결하기를 누르면 QR과 6자리 코드가 나와요.
        2. 폰은 카메라로 QR을 찍고, PC는 이 사이트에서 코드로 들어가기에 6자리를 입력해요.
        3. 이미 연결된 기기 화면에 "들어오려고 해요"가 뜨면 허용을 눌러요. 한 번 허용한 기기는 다음부터 묻지 않아요.

        다시 연결하기

        사이트를 다시 열면 지난번 연결로 자동으로 들어가요. 예전 연결은 첫 화면의 이전에 연결한 기기에서 다시 연결을 누르면 돼요. 연결마다 대화 기록, 모임 앨범, 폴더 동기화 설정이 따로 저장돼요.

        연결된 기기 옆에 "직접 연결 / 중계 연결 / 서버 경유"가 표시돼요. 직접 연결이 가장 빠르고, 서버 경유는 느릴 수 있어요. 직접 연결이면 "통로 4개"처럼 여러 통로로 나눠 보내서 더 빨라요.

        보내거나 받는 동안에는 화면과 PC가 잠들지 않아요(위쪽 "화면 켜 둠"). 끝나면 자동으로 풀려요. 다른 탭을 봐도 전송은 계속돼요.

        파일·글 보내기

        • 파일: 입력줄 왼쪽의 주황색 ＋를 누르거나, PC에서는 파일을 화면 아무 곳에나 끌어다 놓아요. 여러 개를 한 번에 보낼 수 있어요.
        • 폴더째 보내기: PC에서 폴더 버튼을 누르거나 폴더를 끌어다 놓아요. 받는 쪽은 zip으로 저장하거나 파일을 각각 저장해요.
        • 붙여넣기: 복사한 이미지나 파일을 Ctrl+V로 붙여 넣으면 바로 보내져요.
        • 글·링크: 아래 입력칸에 쓰고 Enter(폰은 보내기)를 눌러요. 받은 쪽에는 복사, 링크면 열기 버튼이 붙어요.

        받는 기기 고르기

        기기가 2대 이상 연결돼 있으면 위쪽의 받을 기기에서 보낼 대상을 골라요.

        끊겨도 이어받기

        보내는 중에 와이파이가 끊기면 "끊김"으로 표시되고, 다시 연결되면 받은 지점부터 이어서 보내요. 이어받기는 양쪽 페이지가 열려 있는 동안만 돼요.

        대화 기록

        • 보낸 것은 오른쪽, 받은 것은 왼쪽 말풍선으로 쌓여요. 사진·영상 썸네일을 누르면 크게 볼 수 있어요.
        • 기록은 연결마다 이 브라우저에 저장돼요. 새 연결은 빈 대화창에서 시작하고, 예전 연결로 돌아가면 기록이 다시 보여요.
        • 말풍선의 삭제를 두 번 누르면 상대 기기에서도 지워져요. 위쪽 기록 지우기는 이 연결의 기록 전체를 양쪽에서 지워요. 상대가 지금 연결돼 있지 않으면 다음에 연결될 때 지워져요.
        • 상대가 이미 다운로드했거나 폴더에 저장한 파일은 상대 PC에 남아요.

        기록 보관 기간

        사이드바의 기록 보관에서 7·30·90일을 고르면, 그보다 오래된 파일의 내용만 자동으로 정리하고 메시지와 파일 이름은 남겨요. 기본은 계속 보관이고, 정리 3일 전부터 파일에 표시돼요.

        모임 앨범

        여행이나 행사에서 여러 사람이 찍은 사진을 한곳에 모아요. 폰에서도 돼요.

        1. 모두 같은 연결에 들어와요.
        2. 모임 앨범 탭에서 ＋ 사진 올리기를 눌러 사진·영상을 골라요. PC는 끌어다 놓아도 돼요.
        3. 사진이 찍은 시간순으로 합쳐지고, 연사처럼 비슷한 사진은 "비슷한 사진 N장"으로 묶여요.
        4. 원하는 사진을 선택해서 원본 받기를 누르면 원본으로 저장돼요(PC는 zip, 폰은 공유 메뉴).

        올릴 때는 작은 미리보기만 모두에게 가요. 원본은 올린 사람(또는 이미 원본을 받은 사람)이 연결돼 있을 때 받을 수 있어요. 사진은 서버에 저장되지 않아요.

        폴더 동기화 (PC ↔ PC)

        내 PC의 폴더를 상대 PC와 맞춰요. 처음엔 전부, 그다음부터는 바뀐 파일만 보내서 zip으로 옮기는 것보다 훨씬 빨라요. PC의 크롬·엣지, https 주소에서만 돼요.

        1. 폴더 동기화 탭에서 공유할 폴더 고르기를 눌러요.
        2. 연결된 PC 옆의 이 기기와 공유를 눌러요.
        3. 상대 PC에서 받을 위치 고르기를 누르면, 고른 위치 안에 같은 이름의 폴더를 만들어 받아요.
        4. 파일을 고치면 몇 초 안에 공유하기가 켜져요. 같으면 "✓ 같아요"로 꺼져 있어요.

        알아 두면 좋은 것

        • 동기화 확인을 누르면 내 폴더와 상대 폴더를 지금 다시 훑어서 비교하고, "파일 N개 모두 같아요" 또는 "다른 파일 N개"로 알려 줘요. 양쪽 파일 개수와 마지막 확인 시각도 함께 보여요.
        • 변경 목록 보기로 추가·수정·삭제된 파일을 보고, 텍스트 파일은 바뀐 줄을 볼 수 있어요. 히스토리에는 지난 동기화 기록이 남아요.
        • 보내기 전에 예상 시간이, 보내는 중에는 남은 시간이 표시돼요. 작은 파일은 묶어서, 텍스트는 압축해서 보내요(받는 쪽에는 원래 파일로 저장).
        • 제외 규칙은 .gitignore와 같은 문법으로 한 줄에 하나씩 적어요. .git/, node_modules/ 는 기본으로 빠져요.
        • 한 방향이에요. 받는 PC에서 고친 파일은 다음 공유 때 보내는 쪽 내용으로 덮어써져요.
        • 공유 폴더 설정은 연결마다 따로 저장돼요. 공유 끊기를 누르면 진행 중인 전송도 바로 멈춰요.
        • 보내는 중에 새로고침하거나 연결이 끊겨도, 다시 연결되면 남은 파일을 자동으로 이어서 보내요. 보내는 중에 제외 규칙을 바꾸면 보내기가 끝난 뒤 새 규칙으로 다시 비교해요.
        • 브라우저를 다시 열면 폴더 접근 허용을 한 번 눌러야 할 수 있어요. 크롬에서 "방문할 때마다 허용"을 고르면 다음부터 묻지 않아요.

        받은 파일 저장

        • 기본은 대화창의 저장을 눌러 다운로드 폴더에 저장하는 방식이에요. 폰은 공유 메뉴가 떠서 사진 앱에 저장할 수 있어요.
        • PC(크롬·엣지)에서 사이드바의 바로 저장할 폴더 지정을 해 두면, 받는 즉시 그 폴더에 자동으로 저장돼요. 큰 파일도 메모리를 쓰지 않아서 수십 GB도 받을 수 있어요.
        • 같은 이름의 파일이 있으면 덮어쓰지 않고 "이름 (1)"로 저장해요.

        알림

        다른 창을 보고 있을 때 파일이나 글이 오면 알림으로 알려 줘요.

        • 처음 들어왔을 때 뜨는 알림 켜기나 오른쪽 위 종 버튼을 누르고, 브라우저 허용 창에서 허용을 눌러요.
        • 허용 창이 안 보이면 주소창의 종 모양이나 자물쇠 아이콘을 눌러 알림을 허용해요.
        • 알림은 https 주소에서만 돼요. 아이폰은 홈 화면에 추가한 경우에만 돼요.

        보안

        • 종단간 암호화: 파일과 글은 두 기기만 아는 키로 암호화돼요. 서버를 거쳐도 서버는 내용을 볼 수 없어요(https 주소에서 켜짐).
        • 보안 코드: 연결된 기기 아래의 6자리 보안 코드가 두 기기에서 같으면 중간에서 가로챈 사람이 없다는 뜻이에요. 중요한 파일을 보낼 때 한 번 비교해 보세요.
        • 입장 승인: 모르는 기기가 들어오려 하면 거절을 눌러요.
        • 코드 대입 차단: 코드를 10번 틀리면 10분 동안 코드 입장이 막혀요. QR·링크로는 들어올 수 있어요.
        • 파일은 서버에 저장되지 않아요. 기록은 각 기기의 브라우저에만 있어요.

        문제 해결

        "서버를 깨우는 중이에요"가 떠요
        무료 서버라 한동안 안 쓰면 잠들어요. 30초~1분 기다리면 연결돼요.
        폴더 동기화·알림이 안 보여요
        http 주소로 열면 꺼져요. 배포한 https 주소로 열어 주세요. 폴더 동기화는 PC의 크롬·엣지에서만 돼요.
        업데이트 뒤에 예전 화면이 보여요
        새로고침을 한 번 해 주세요. 다른 탭에 예전 버전이 열려 있으면 그 탭도 닫거나 새로고침해 주세요.
        전송이 느려요
        연결된 기기 옆 표시가 "서버 경유"면 직접 연결이 막힌 네트워크예요. 같은 와이파이에서 쓰거나, 관리자가 TURN 중계를 설정하면 빨라져요.
        폴더 동기화가 멈춘 것 같아요
        상대 응답이 30초 없으면 남은 파일만 자동으로 다시 보내요(최대 3번). 그래도 멈추면 상대 화면이 열려 있는지 확인하고 공유하기를 다시 눌러요. 이미 받은 파일은 건너뛰어요.
        "코드 입장이 막혔어요"가 떠요
        코드를 여러 번 틀려서 10분 동안 막힌 거예요. 기다리거나 QR·링크로 들어오세요.
