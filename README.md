# 옮겨

폰·PC·태블릿 사이에서 파일과 글을 원본 그대로 주고받는 웹앱입니다. 기종과 방향에 상관없이 됩니다(아이폰 ↔ 갤럭시, 폰 ↔ PC, PC ↔ PC).

## 실행

```bash
npm install
npm start
```

서버가 켜지면 주소가 두 개 나옵니다.

- `http://localhost:8080`: 이 PC에서 열 때
- `http://192.168.x.x:8080`: 같은 와이파이의 폰이나 다른 PC에서 열 때 (QR에 자동으로 들어갑니다)

처음 실행할 때 Windows 방화벽이 Node.js 허용 여부를 물으면 **개인 네트워크 허용**을 눌러야 폰에서 접속할 수 있습니다.

## 쓰는 법

1. 한 기기에서 **새로 연결하기**를 누르면 QR과 6자리 코드가 나옵니다.
2. 폰은 카메라로 QR을 찍고, PC는 사이트에서 코드를 입력합니다.
3. 파일을 고르거나 끌어다 놓거나 붙여 넣으면 연결된 기기로 넘어갑니다. 글과 링크도 보낼 수 있습니다.
4. 다음에 사이트를 열면 지난번 연결로 자동으로 다시 들어갑니다.

## 구조

- `server.js`: 정적 파일 제공, 기기끼리 서로를 찾게 해 주는 중개(WebSocket 시그널링), 직접 연결이 안 될 때 데이터 중계
- `public/app.js`: WebRTC 데이터 채널로 기기끼리 직접 전송합니다. 6초 안에 직접 연결이 안 되면 서버 경유로 자동 전환합니다. 파일 하나는 시작한 통로로 끝까지 보내서 조각 순서가 섞이지 않습니다.
- 받는 쪽은 32MB마다 조각을 Blob으로 묶어서 큰 파일도 메모리를 덜 씁니다.

## Render 무료 배포

1. 이 폴더를 GitHub 저장소로 올립니다.
2. [Render](https://render.com)에 GitHub 계정으로 가입합니다.
3. **New → Blueprint**를 누르고 저장소를 고르면 `render.yaml` 설정대로 무료 웹 서비스가 만들어집니다.
4. 몇 분 뒤 `https://omgyeo-xxxx.onrender.com` 같은 주소가 생깁니다.

무료 플랜은 15분 동안 접속이 없으면 잠들고, 다음 첫 접속 때 깨어나는 데 30초~1분이 걸립니다. GitHub에 새로 올리면 자동으로 다시 배포됩니다.

## HTTPS (선택)

`cert/key.pem`, `cert/cert.pem`이 있으면 HTTPS로 실행됩니다. HTTP에서는 폰 브라우저가 다음 기능을 막습니다.

- 받은 글 **복사 버튼**: 대신 글을 길게 눌러 복사합니다.
- 아이폰의 **공유 메뉴로 사진 앱에 저장**: 대신 파일 앱의 다운로드 폴더에 저장됩니다.

인터넷에 배포하면(HTTPS 호스팅) 이 제약이 사라지고 같은 와이파이가 아니어도 연결됩니다.

## 알려진 한계

- 전송하는 동안 양쪽 모두 페이지를 열어 두어야 합니다. 아이폰은 다른 앱으로 넘어가면 연결이 끊깁니다.
- 폰 브라우저는 수 GB 파일에서 메모리가 모자랄 수 있습니다.
- 서버 경유 전송은 서버를 거치므로 서버 운영자를 믿을 수 있어야 합니다. 직접 연결은 WebRTC 기본 암호화(DTLS)가 적용됩니다.
- 회사·학교처럼 직접 연결을 막는 네트워크에서 인터넷 배포 버전을 쓰면, 서버 경유 트래픽만큼 서버 대역폭이 듭니다.
